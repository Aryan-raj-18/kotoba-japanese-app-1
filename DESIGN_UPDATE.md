# Kotoba Journey design — version 1.0.0, build 28

Sakura Journey is the default light appearance. Follow device appearance chooses Kyoto Night in dark mode. Water Glass is the third featured theme. Existing explicit theme choices remain selected; the six other palettes are available under More palettes.

The dashboard now gives the recommended lesson a clear Continue learning action, shows actual saved progress, previews the next three roadmap chapters, and groups the existing learning sections. A still vector landscape changes its colors and details with the theme. Small chapter covers and the retained Koto companion add personality. The daily-goal shortcut opens the existing Settings controls.

The Kotoba logo and offline classic serif/Japanese Mincho fonts remain fixed. Navigation symbols now share consistent shapes across palettes. Study surfaces use calm semantic colors and selected-answer feedback remains clearly visible. Water Glass limits added blur to the navigation/header; ordinary lesson cards remain readable solid surfaces. Brief feedback respects reduced motion. No looping animation was added to the dashboard landscape.

All course content and learning functions are retained. Login/signup remain absent. Local saving, offline lessons, intro handoff, list batching, versioned static caching, Back context and coordinated playback/microphone controls remain. The optional Firebase backend is still disabled until configured.

Automated regressions, packaged page/API smoke checks and desktop browser layout/interaction checks are documented in VERIFICATION.json and verification/. Browser screenshots illustrate the implemented UI. Physical Android rendering, font scaling, gestures, launch/resume and Play internal-track checks still need to be completed before production release.
